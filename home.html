HASH

Passwords, hashed only

bcrypt hashing with a per-password salt. Plaintext never touches the database, not even briefly.

RATE

Brute-force resistant

Per-IP rate limiting plus a per-account lockout after repeated failed attempts.

ORM

Injection-safe queries

Every query runs through SQLAlchemy's parameterized query API — no string-built SQL, anywhere.

CSRF

Forms carry a token

Every state-changing form is protected by a per-session CSRF token, checked on submit.

SESS

Sessions, server-verified

HttpOnly, SameSite cookies with a 30-minute idle timeout and strict session protection.

TOTP

Optional two-factor

Time-based one-time codes via any authenticator app, required after password verification.
